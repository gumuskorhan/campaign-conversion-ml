# Campaign Conversion ML

## Business Problem
Pazarlama kampanyalarında iletişim kurulacak müşterileri
dönüşüm olasılıklarına göre önceliklendirmek ve sınırlı
iletişim kapasitesinin daha etkin kullanılmasını desteklemek.

## Prediction Goal
Müşteriyle iletişime geçilmeden önce, müşterinin kampanyaya
olumlu yanıt verme olasılığını tahmin etmek.

## Data Policy
Only public or synthetic datasets will be used.
No company data will be used.
